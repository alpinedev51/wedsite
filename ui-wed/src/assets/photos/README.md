# Photos page

The gallery on the Photos page, imported in `src/pages/Photos.tsx`.

To add a photo: drop it here, import it at the top of `Photos.tsx` the same
way as the others, and add a `{ src, alt }` entry to the `photos` list.
Use web copies (about 2400px on the long side, under ~700 KB), not
full-size camera exports.
