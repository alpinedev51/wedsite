# Photos page

Web copies of the photos on the Photos page. Apart from this README,
everything in this folder is generated by `scripts/process-photos.py`, so
don't hand-edit it. The order, sections, and alt text live in
`src/config/photos.ts`.

To add photos:

1. Put the originals (camera JPEGs, iPhone HEICs, any size) in a folder
   **outside the repo**.
2. From `ui-wed/`, run (needs [uv](https://docs.astral.sh/uv/), which
   installs Pillow and a HEIC decoder on first run):

   ```sh
   uv run scripts/process-photos.py ~/path/to/originals
   ```

   For each photo this writes `<slug>-<width>w.avif` in up to 3 sizes,
   a `<slug>.webp` fallback, and an entry in `manifest.json`. The slug is
   the lowercased filename (`IMG_2861.HEIC` -> `img-2861`). Encoding takes
   a while: roughly 15 seconds per full-size camera photo.

3. Add `{ slug, alt }` for each photo to a section in
   `src/config/photos.ts`.

The script applies the camera's rotation, keeps the colour profile (iPhone
photos are Display P3), strips EXIF/GPS, and never upscales. Settings
(AVIF q80) were picked by measuring against the originals; see the script's
header for details.
