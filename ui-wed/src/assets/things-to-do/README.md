# Things to Do photos

Photos for the activity cards and their pop-ups on the Things to Do page,
imported in `src/pages/ThingsToDo.tsx`.

To add one: drop it here, import it at the top of `ThingsToDo.tsx`, and add
it to that activity's `photos` list. Files ending in `_web` are 1600px
re-encodes of larger originals; aim for that size or smaller (a few
hundred KB).
